# DevFolio

A modern and responsive personal portfolio website built with HTML, CSS, JavaScript, and Bootstrap.

## 📌 Features

- Responsive design for all devices
- Modern and clean user interface
- Smooth scrolling navigation
- Portfolio showcase section
- About section
- Services section
- Contact section
- Built with Bootstrap for faster and responsive development

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5


## 📱 Responsive Design

The website is fully responsive and optimized for:

- Desktop
- Tablet
- Mobile Devices

## 🎯 Purpose

This project was created to practice and demonstrate front-end development skills using HTML, CSS, JavaScript, and Bootstrap.
